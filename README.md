# 🛡️ 推特百宝箱 - X 评论盾牌

> X (Twitter) 评论管理工具 —— 自动清理无用评论、折叠侧栏，给你一个干净的阅读体验。

![version](https://img.shields.io/badge/version-1.6.3-blue)
![license](https://img.shields.io/badge/license-MIT-green)

## ✨ 功能特性

### 评论清理
- **自动扫描评论**：进入推文详情页后自动扫描已加载的评论（不会自动滚动页面，阅读不被干扰）
- **多规则过滤**：
  - 关键词黑名单（默认：广告、抽奖、telegram、博彩、follow me）
  - 用户黑名单
  - 自定义正则规则
- **智能屏蔽**：命中规则的评论替换为"🚫 已隐藏评论"占位块，可查看原因
- **历史记录**：本地保存处理记录（上限 500 条），支持查看与导出 JSON

### 界面优化
- **隐藏右侧栏**（可选）：一键隐藏推荐/趋势栏，主内容加宽
- **折叠左侧栏**（可选）：隐藏左侧导航，主内容居中显示
- **悬浮盾牌按钮**：可自由拖动位置，点击打开/收起控制面板（面板本身也可拖动）

### 安全设计
- **自动拉黑默认关闭**：开启时有二次确认弹窗，避免账号风控风险
- **数据仅存本地**：所有配置和记录使用 GM_setValue 保存在浏览器，不上传任何数据

## 📦 安装

### 环境要求
- 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/)（油猴）扩展
- 支持 Chrome / Edge / Firefox / Safari

### 安装步骤
1. 打开脚本安装地址：
   ```
   https://raw.githubusercontent.com/liuGuanYi-hub/x-comment-shield/main/x-comment-shield.user.js
   ```
2. Tampermonkey 自动弹出安装页，点击「安装」
3. 打开 [X (Twitter)](https://x.com)，页面右下角出现 🛡️ 悬浮按钮即安装成功

## 🚀 使用指南

### 快速开始
1. 点击右下角 🛡️ 盾牌按钮，打开控制面板
2. 可配置：
   - **隐藏右侧栏**：勾选后保存，右侧栏消失
   - **折叠左侧栏**：勾选后保存，左侧导航折叠
   - **关键词**：每行一个，按需增删
3. 点击「扫描评论」手动清理，或进入推文详情页自动清理

### 界面操作
| 操作 | 说明 |
|------|------|
| 点击盾牌 | 打开/关闭控制面板（图标随开合缩放） |
| 按住盾牌拖动 | 移动按钮位置 |
| 按住面板标题栏拖动 | 移动面板位置 |
| 点面板右上角 − | 最小化面板 |
| 点「导出历史」 | 下载处理记录 JSON |

## 🔄 自动更新

脚本通过 `@updateURL` 指向本仓库的 raw 文件，Tampermonkey 会**每天自动检查更新**（也可手动「检查更新」）。版本号变化时提示更新，一键升级。

> 开发提示：更新代码后请同步递增 `@version` 字段，否则油猴不会提示更新。

## 🏗️ 代码结构

```
x-comment-shield.user.js
├── Config Module    配置管理（GM_setValue 持久化）
├── CommentScanner   评论扫描与解析（支持滚动加载）
├── Matcher          规则匹配（关键词/用户/正则）
├── Blocker          屏蔽执行（隐藏/替换/历史记录）
├── UI Module        控制面板、悬浮按钮、拖拽交互
└── Main Module      主入口、SPA 路由监听、MutationObserver
```
